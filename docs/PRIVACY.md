# translationApp 隐私声明（Privacy Policy）

生效日期：2026 年 11 月 20 日

`translationApp`（以下简称「本扩展」）是一款开源、无自有后端服务器的浏览器扩展，提供网页划词翻译与 YouTube 视频双语字幕功能。我们高度重视用户数据安全与隐私保护。

## 1. 我们收集或存储哪些数据

本扩展**不设立任何开发者自有服务器，不收集、不上传、不出售任何个人身份信息、浏览历史或遥测统计数据**。

所有运行数据仅保存在您本地浏览器的 `chrome.storage.local` 中，包括：

- **偏好设置**：目标语言、所选翻译引擎标识、全局功能开关、站点黑名单域名列表。
- **自定义引擎凭据（可选）**：当您主动选择「OpenAI 兼容大模型」引擎时填写的接口地址（Base URL）、API Key 与模型名称。API Key 仅保存在您的本地浏览器扩展存储中，且仅在扩展后台（Background Service Worker）向您指定的接口发起请求时使用，绝不注入网页 DOM 或主世界脚本。
- **本地翻译缓存**：近期已翻译文本与对应译文的本地缓存（最多保留最近 500 条），用于减少重复请求与加速显示。您可随时在扩展设置页点击「清除翻译缓存」一键清空。

## 2. 翻译文本的传输去向

本扩展仅在以下两种由您主动触发或开启的场景下，将待翻译文本直接从您的浏览器发送至您所选的第三方翻译服务商：

1. **网页划词翻译**：当您在网页中选中文本并主动点击「翻译」浮层按钮时，发送所选文本片段（不会自动上传整页内容）。
2. **YouTube 双语字幕**：当您在启用字幕翻译开关的状态下观看 YouTube 视频时，读取该视频的字幕文本并分批发送至所选翻译引擎。

根据您在设置页选择的引擎，文本将直连发送至对应服务商：

- **默认引擎（Edge 免费端点）**：请求直接发往微软翻译接口（`https://edge.microsoft.com/translate/translatetext`），遵循 Microsoft 隐私声明。
- **OpenAI 兼容大模型引擎**：请求直接发往您在设置页自行配置的 `Base URL`（如 OpenAI、DeepSeek、Moonshot 等服务商），遵循对应服务商的隐私政策与数据处理条款。

## 3. 浏览器权限最小化说明

| 权限 / 注入范围 | 用途说明 |
| --- | --- |
| `storage` | 在本地保存语言/引擎设置、站点黑名单与翻译结果缓存 |
| `activeTab` | 仅在您点击工具栏扩展图标打开弹窗时，读取当前活动标签页域名以展示与切换「在此站点启用」状态（不申请常驻 `tabs` 浏览历史权限） |
| Content Scripts（`*://*/*` 与 `*://*.youtube.com/*`） | 在网页内使用 Shadow DOM 展示划词翻译按钮/卡片，以及在 YouTube 播放器内叠加同步双语字幕 |

## 4. 数据控制与删除

- 您可随时在扩展「设置」页修改或删除 API Key、清空本地翻译缓存，或管理站点黑名单。
- 卸载本扩展时，浏览器会自动彻底清除本扩展在本地保存的所有配置与缓存数据。

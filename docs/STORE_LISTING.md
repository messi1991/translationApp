## 2. 商店详细描述（Detailed Description）

**translationApp** 是一款专注于「网页阅读划词」与「YouTube 视频双语字幕」的轻量级 Chrome 扩展。无账号体系、无自有中转服务器、无广告与追踪代码，开箱即用，同时支持自带 API Key 接入任意 OpenAI 兼容大模型获得更高翻译质量。

### 核心特性

1. **网页划词翻译（防误触设计）**
   - 选中文本出现轻量「翻译」按钮，点击后才发起请求，避免阅读选中时误触和浪费额度
   - Shadow DOM 样式完全隔离，展示原文、译文、源语言与引擎徽标，支持一键复制与失败重试

2. **YouTube 原生级双语同步字幕**
   - 自动识别视频原声语言轨道，支持手动字幕与自动语音识别（ASR）单词级智能断句重组
   - 按当前播放进度智能分批预翻译，拖动进度条（Seek）即时重算
   - 基于 `requestVideoFrameCallback` 帧级时间同步，2 倍速、暂停、剧院模式与全屏均零漂移

3. **多引擎自由切换（免费内置 + 自带大模型 Key）**
   - 默认内置 Edge 免费翻译端点，安装即可直接使用，无需注册配置
   - 支持所有 OpenAI Chat Completions 兼容接口（OpenAI、DeepSeek、Moonshot、通义千问、本地 Ollama 等），支持连通性一键测试

4. **极简管控与隐私优先**
   - 工具栏弹窗一键切换「划词翻译」「YouTube 双语字幕」及「在此站点启用」，无需刷新网页立即生效
   - 本地二级缓存加速重复词句展示；所有配置与 API Key 仅保存在浏览器本地，仅从后台直连目标翻译接口

## 3. 审核权限理由（Permission Justifications）

在 Chrome Web Store 开发者后台「隐私权实践（Privacy Practices）」页面可按以下说明填写：

- **`storage`**：用于在用户本地存储目标语言、翻译引擎选择、站点黑名单以及本地翻译缓存，避免每次打开网页重复配置与重复请求。
- **`activeTab`**：仅当用户主动点击浏览器工具栏上的扩展图标打开弹窗时，获取当前标签页域名以提供「在此站点启用/禁用」快捷开关，不后台监控标签页记录。
- **主机匹配（Content Scripts `*://*/*` & `*://*.youtube.com/*`）**：用于在用户浏览任意网页选中文本时渲染 Shadow DOM 划词翻译浮层，以及在 YouTube 视频观看页读取公开播放器字幕轨道并在播放器内部渲染双语字幕叠加层。
- **远程代码（Remote Code）**：**否（No）**。扩展所有逻辑均打包在安装包内，不加载或执行任何远程脚本。
